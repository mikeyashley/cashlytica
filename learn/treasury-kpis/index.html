Treasury KPIs

Treasury KPIs should be tied to decisions the CFO actually cares about: cash visibility, forecast quality, fee leakage, yield efficiency, and control.

If a metric does not drive an action, it is probably not the right KPI.

Useful KPIs

  • Cash visibility coverage
  • Forecast accuracy
  • Fee leakage found
  • Yield drag reduced
  • Reconciliation exception rate
  • Time to close a weekly cash review

How to read them

  • Look for trend, not a single point in time.
  • Tie each metric to one owner and one operating review.
  • Keep the list small enough to use weekly.
