Cash Position Dashboard

A cash position dashboard should answer one question immediately: how much cash is available right now, and what changed since the last update?

If it does not make the answer obvious, it is not doing enough work.

Dashboard essentials

  • Current available cash, by account, entity or bucket
  • Change from the prior period
  • Flags for what moved the number
  • Links to forecast and bank-to-books detail

What the dashboard is for

  • Quick decisions
  • A shared view for finance and treasury
  • A bridge into the forecast and the weekly briefing rather than a dead end

How Cashlytica shows it

Cashlytica's cash position shows balances by company and entity, with the source and freshness of each balance and the difference between available and current cash. Balances that come only from the books are labelled as estimates.
